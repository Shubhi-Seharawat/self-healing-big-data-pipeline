# Project Evidence

This folder contains evidence collected during the development of the Self-Healing Big Data Pipeline project.

The evidence documents:
- PySpark environment setup
- VTA GTFS dataset download and extraction
- Data loading, schema inspection, and missing-value profiling
- P0 baseline and Parquet verification
- Controlled fault injection and detection
- Recovery, quarantine, and preliminary evaluation results

The screenshots and results are intended to document the development process and initial experiments.
